I'm a programmer who doesn't like sitting still and I'm looking for work!

To the side is an informal resume, but this is also a place where you can check
out projects, play games, read ramblings, and even book me as a tutor or jazz pianist.

The site's development will definitely be work-in-progress for a while. I prefer

like one of my game projects, with little secrets and surprised all over the

As a pianist, I like blues and old jazz the most, but I also play a lot of latin,
and I'll definitely be posting all my Danilo Perez charts here.

# Welcome to my personal page (for programmers)
The central conceit of this site is that it uses a custom extended markdown
syntax powered by remark and astro. The build chain compiles the markdown to
ugly, ugly html, then embeds it into astro components to render them on screen.

Custom tags allow me to embed images, videos, and html out of line or inline, and use custom styling on those elements.
Along with some other features I add when I get bored.
The main advantage is avoiding html and css, which are simply less egonomic than markdown
and overly for keeping simple articles. I've also been using markdown to write
personal notes for years, both via github and obsidian. This way, I can import
some of those notes directly.

The main page and sidebar took two afternoons between work and tutoring to set up with Big Pickle.
Like most vibecoded projects, it seems to work pretty well. 
Alongside this, I am doing a no-AI project with lexers and asts, so my hope is
to come back to remark when that project is done and learn how it works.
