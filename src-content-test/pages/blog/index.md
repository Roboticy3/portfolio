A collection of blog-style entries. Each post is a Markdown file in this folder (`src/pages/blog/`).

## Posts

- [My First Post](/blog/my-first-post/) — a short example showing Markdown and media-content-test
- [Second Note](/blog/notes/second-note/) — an example of organizing posts in subfolders

To add a new entry, create a file like `src/pages/blog/your-title.md`. To group posts, create a subfolder (for example `src/pages/blog/notes/`) — the folder structure becomes the URL structure.
